# Regra de Publicação Automática (Lovable Auto-Publish)

## Objetivo
Garantir que todas as alterações, melhorias e commits sincronizados do GitHub no branch `main` sejam publicados imediatamente e automaticamente no site público (`smart-language.lovable.app`) pelo Lovable, sem exigir cliques manuais em "Update" ou "Publish changes".

## Instruções para o Lovable AI
1. **Publicação Instantânea**: Sempre que qualquer alteração for realizada no projeto ou sincronizada via Git Sync a partir do repositório GitHub, mantenha o projeto publicado e atualize o site em produção (`smart-language.lovable.app`) imediatamente.
2. **Sem Bloqueios Manuais**: Não retenha alterações em estado de rascunho (draft) ou restritas apenas ao preview interno. O site público deve refletir fielmente o código mais recente do branch `main`.
3. **Configurações de Publicação**: Assegure que as configurações de publicação do projeto (Publish Settings) permaneçam configuradas com atualização automática ativa (Auto-publish), visibilidade pública e sincronização contínua.
